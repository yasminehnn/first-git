# CSC649 My First Python Program in PyCharm

Description : This program accepts a sentence from the user and calculates the number of words and characters in the sentence. It also displays a suitable message when the user enters an empty input.

## How to Run : 
1. Open the project in PyCharm.
2. Make sure the project is using Python 3.12.
3. Open 'main.py' under your project.
4. Run the program by clicking the 'play' button at top right of the codes.
5. Enter a sentence when prompted.

## Test Results :

| Test            | Input                    | Expected Result                                                                |
|-----------------|--------------------------|--------------------------------------------------------------------------------|
| Normal sentence | `I love learning Python` | Word count: 4, Character count: 22                                             |
| Empty input     | No input                 | Displays "You did not enter a sentence."                                       |
| Extra spaces    | `I    love    Python`    | Word count: 3, Character count: 19 with spaces included in the character count |

The program produced the expected results for all three test cases.

## Limitation : 
The program only performs word and character counting. It does not analyse punctuation, sentences, or the meaning of the text. "# first-git"
